# ClownVoiceCommand

Speaking training app. Five daily drills, recorded reps with live mic stats, Claude scoring (optional API key), progress synced between PC and iPhone through Firebase.

Live: https://cashclowns.github.io/ClownVoiceCommand/

Files: index.html (app), config.js (Firebase web config), sw.js (offline cache), manifest.webmanifest and icons (home-screen install), firestore.rules (data is private per signed-in user).
